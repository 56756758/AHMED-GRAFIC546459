# AZ STORE 🎮 | متجر الألعاب الاحترافي

**AZ STORE** هو منصة ويب احترافية وعصرية متخصصة في بيع وشراء حسابات الألعاب، وشحن النقاط والجواهر والعملات لجميع الألعاب مع تركيز خاص على **FC Mobile (FIFA)** و **eFootball / PES Mobile**، بالإضافة إلى **PUBG Mobile** و **Valorant** و **Free Fire**.

---

## 🌟 مميزات المتجر

- 🎨 **تصميم Gaming نيون فاخر:** ألوان رئيسية (الأزرق النيون `#00d2ff`، الأحمر الناري `#ff0055`، ولمسات بنفسجية `#8338ec`) بخلفيات داكنة وتأثيرات Glow متناسقة.
- 📱 **متجاوب بالكامل (Fully Responsive):** تجربة استخدام سلسة وسريعة على الجوال، التابلت والشاشات الكبيرة.
- 🌐 **دعم كامل للغة العربية (RTL):** خطوط عربية حديثة وعالية الوضوح (Cairo & Tajawal & Rajdhani).
- ⚡ **نظام شحن فوري بـ Player ID:** إدخال آيدي اللاعب واختيار الباقة مع حساب فوري للسعر.
- 🏆 **سوق حسابات متكامل:** عرض تقييمات التشكيلات (OVR)، مستوى الحساب، أبرز اللاعبين، وفلترة وبحث مباشر.
- 💼 **نموذج "اعرض حسابك للبيع":** إمكانية إرسال بيانات وتفاصيل الحساب لإدارة المتجر لتقييمه وشرائه.
- 🛒 **سلة مشتريات تفاعلية + إتمام الطلب:** توليد رسالة فاتورة منسقة تلقائياً عبر **WhatsApp** لسرعة التواصل والتنفيذ.
- 🛡️ **أقسام الثقة والضمان والأسئلة الشائعة (FAQs) وآراء العملاء.**

## ⚙️ التخصيص السريع

### 1. تغيير رقم الواتساب:
افتح ملف `js/data.js` أو `js/app.js` وعدّل الرقم:
```javascript
whatsappNumber: '966500000000' // استبدله برقم هاتفك بصيغة دولية بدون +
```

### 2. إضافة أو تعديل باقات الشحن أو الحسابات:
يمكنك إضافة أو تعديل أي لعبة أو حساب في ملف `js/data.js` داخل المصفوفات:
- `topupGames`: لإضافة ألعاب جديدة وباقات شحن.
- `gameAccounts`: لإضافة حسابات جديدة مع الـ OVR والصور والسعر.
